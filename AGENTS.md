# Instructions for Antigravity Coding Agent

When working on this repository:
1. Always consult [`docs/ANTIGRAVITY_BUILD_AUDITOR.md`](docs/ANTIGRAVITY_BUILD_AUDITOR.md) after milestones and before releases.
2. Follow its non-negotiable safety rules and bounded repair loop.
3. Never claim tests passed without command execution evidence.
4. Preserve existing user changes and product features.
5. Produce the required build report after each audit run.
6. Stop and request human approval before any destructive actions or external production credential changes.
